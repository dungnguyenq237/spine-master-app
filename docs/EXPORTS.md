# Export behavior

- Separate offline renderer; no MediaRecorder, captureStream, preview timing, or lossy thumbnail sources.
- Timeline range is [start, end); frames = ceil(duration × effective FPS). Include-final adds an explicit endpoint frame and therefore one frame interval to container duration. Each selected timeline repeat restarts and replays from setup to the trim start. Physics continuity across repeats is not implied.
- Fixed simulation updates advance sequentially. A partial step reaches each requested sample. This is deterministic for a fixed configuration; cross-FPS equivalence and physics correctness require fixture validation. Preview backward scrubbing replays from setup.
- Auto framing unions geometric bounds across every output sample, then replays for output. Geometric bounds can omit screen effects; use padding/custom crop. Tight crop is auto bounds with zero padding. Fixed/custom framing uses world coordinates and output-aspect expansion.
- Supersampling renders 1×/2×/4×, then browser high-quality 2D downsampling and top-down RGBA readback. This conservative baseline is not gamma-correct Lanczos. No measured fidelity claim is made.
- Readback uses the browser canvas compositor to obtain straight RGBA. The exact runtime framebuffer/blend path remains subject to visual reference checks, particularly additive and mixed alpha edges. Mixed-PMA atlas pages are rejected on pre-4.3 adapters; 4.3 supplies PMA per texture. Context compositing uses premultipliedAlpha=true, separate from atlas texture upload behavior.
- Raw binary Tauri IPC sends one frame at a time and waits for native acknowledgement. No JSON/base64 video frames, giant arrays, or unbounded producer queue.
- MP4: libx264, yuv420p, explicit solid background, fast-start, BT.709 matrix/metadata. Quality defaults: fast CRF20/veryfast, balanced CRF18/medium, high CRF16/slow, maximum CRF14/veryslow. Defaults are starting points, not benchmark-backed claims.
- GIF: FFV1/BGRA disk intermediate, separate global palette generation and paletteuse pass. Timing is quantized to a constant nearest centisecond delay: effective FPS = 100 / round(100 / requested FPS). 24 → 25, 30 → 33.33, 60 → 50. The UI displays this difference. Palette defaults to 256 colors, Sierra 2-4A; Bayer and no dither are alternatives. Repeat controls playback repeat metadata separately from timeline repeats.
- PNG: straight RGBA, zero-padded numbering and manifest. Sprite sheets use a fixed grid and multiple pages within an 8192px/32-megapixel page budget; manifest records columns, rows, cell size, padding and total frame count. Last-page unused cells are transparent.
- ProRes: prores_ks profile 4 / yuva444p10le. VP9: libvpx-vp9 / yuva420p / auto-alt-ref disabled. Container support does not prove player alpha support. These routes are experimental until visual alpha validation.
- Jobs stage in a unique destination subfolder. FFprobe checks video codec/dimensions/frame count/timing, transparent-video first-frame decoding checks alpha presence when the input contains alpha, and full decoding catches bitstream errors before finalizing. PNGs decode before finalization. This is runtime output validation, not a substitute for the deferred project test suite.
- Atomic directory reservation prevents overwriting prior output. Each export receives its own directory with media and manifest; complete payload is renamed atomically into `export/`. Cancellation removes the active staging directory. Process interruption or power loss can leave `.spine-export-*` staging folders for manual recovery/removal.
- Native encoder selection is explicit and session-local. Pick a trusted executable; matching ffprobe must live beside it. No shell interpolation and no encoder binaries included.
